# Sessiz Korna Simülatörü

> Trafikte kornaya basmak yasaklandığında medeniyet çökmedi. Sadece içinden basmaya başladı.

Bu depo, **ISO-KORNA-404** standardının resmi referans uygulamasıdır.  
Amaç: korna sesini üretmeden korna niyetini iletmek.  
Sonuç: mahalle sakinleri mutlu, kedi uyanmadı, trafik yine durdu.

## Kurulum

```bash
python3 korna.py
```

Daha çok (ama yine sessiz) korna için:

```bash
python3 korna.py 7
```

## Teknik Özellikler

- Gecikme süresi tam **3 saniye**. Neden 3? Çünkü her resmi işlem 3 saniye geç başlar.
- Çıktı tamamen görsel. Kulaklarınız tatil yapabilir.
- Rastgele yorum üretir. Yorumlar bilimsel değildir, vicdanidir.
